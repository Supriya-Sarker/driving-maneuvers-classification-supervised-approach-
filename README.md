# GoLang REST API with Kubernetes Helm Chart Example Project

## A fully functional Example project written in Go showing how to create a REST API and deploy Kubernetes

This project is an example that was built along with a YouTube series showing how to create a custom REST API in Golang. Every part of the project is sample code that shows how to do the following. 

* Create a custom web server with Golang using HTTPRouter
* Create a simple REST API that serves YouTube states (as an example use case)
